# Thư mục `public/imgs`

## Nhóm asset

- `avatar/`: avatar dùng bởi HTML UI.
- `nhan-vat/`: spritesheet nhân vật Phaser.
- `quai-vat/`: spritesheet quái.
- `lang/`: ảnh map và màn auth.
- `chuong/`: projectile render trong Phaser.
- `skill/`: icon kỹ năng cho HTML UI.
- `common/`: icon dùng chung.

Giữ tên file chữ thường, không dấu, dùng dấu gạch ngang khi cần. Cập nhật config/code khi đổi tên asset.
